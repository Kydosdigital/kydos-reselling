# Programme Onboarding Automation

## Trigger

Successful programme payment and completed required agreement/checkout process.

## CRM actions

1. Apply tag:
Programme Participant

2. Apply tier tag:
- Blueprint
- Build With Us
- Done For You

3. Move opportunity:
Paid / Onboarding

4. Create participant record.

5. Record:
- purchase date
- programme tier
- programme start
- support end date
- implementation owner

## WhatsApp welcome

Use the approved WhatsApp Support Process welcome message.

## Internal tasks

### Blueprint

- review intake
- confirm launch pace
- give portal access
- set 8-week support end
- send startup checklist

### Build With Us

- review intake
- assign implementation owner
- schedule setup call
- set 12-week support end
- create implementation board
- brand/domain/website task
- CRM task
- recruitment task
- Meta launch task

### Done For You

- assign implementation lead
- create full build board
- schedule kickoff
- company setup
- brand
- website
- CRM
- recruitment
- operations
- launch
- handover
- set 90-day support end after formal handover

## Portal access

Send:

- login
- Start Here link
- roadmap
- download library
- support contact

## Status changes

On intake completed:

Move:
Onboarding -> Build Active

On launch ready:

Move:
Build Active -> Launch Ready

On first campaign live:

Move:
Launch Ready -> Live

For Done For You:

After handover:
Live -> Handover Support
