# WhatsApp Support Process

## Participant onboarding

At programme start record:

Participant:

Tier:

Start date:

Support end date:

Kydos support owner:

## Welcome message

Hi [Name], welcome to the Kydos Digital agency programme.

This WhatsApp chat is for implementation questions during your active support period.

Your support period runs until [date].

The written programme library remains the main source of truth, so when you ask a question we may point you to the relevant guide and then help with anything that is still unclear.

For anything involving personal tax, legal or immigration advice, we will refer you to the relevant professional.

Welcome aboard.

## Handling questions

### Simple

Answer directly and point to relevant document.

### Implementation blocker

Ask for:
- screenshot
- system
- expected result
- actual result

Then troubleshoot.

### Scope request

If participant is asking Kydos to do work not included:
- explain scope
- offer add-on quotation if appropriate

### Professional-advice question

Refer to:
- accountant
- solicitor
- immigration adviser

Do not guess.

## Internal records

For meaningful decisions:
- update participant record
- update implementation checklist
- update Source of Truth if it changes the programme generally

## Support ending

7 days before end:

Send reminder.

Example:

"Your active WhatsApp support period ends on [date]. Your programme materials remain available. If there is anything in your current implementation you want us to clarify before the support period closes, please send it through this week."

## After support

Do not abruptly ignore the participant.

Respond with:
- support period has ended
- relevant document
- paid support option where needed
