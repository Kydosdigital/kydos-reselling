# Build With Us, £5,000

## Purpose

For a participant who wants the Kydos operating system plus hands-on implementation of the core agency infrastructure.

## Payment

£5,000 paid in full before implementation begins.

## Included

Everything in Blueprint, plus the following implementation support.

### Company setup

Kydos supports the participant through:

- company-formation process
- ANNA Money route where suitable
- business-bank setup guidance
- FreeAgent/accountant setup guidance

Professional accounting, legal and immigration advice remains with the relevant independent professional.

### Branding

Participant supplies the business direction and required information.

Kydos creates:

- logo
- colour palette
- typography direction
- basic brand guidelines

### Website

Kydos builds one standard five-page agency website.

The participant may choose the five pages.

Included:

- responsive build
- standard contact/booking integration
- basic on-page SEO
- analytics/tracking readiness
- CRM lead connection where in scope

Not automatically included:

- ecommerce
- custom software
- large portals
- complex integrations
- pages beyond five
- major bespoke functionality

### CRM

Kydos configures the participant's branded CRM.

Includes:

- agency branding
- users
- sales pipeline
- booking calendar
- lead fields
- tags
- email/SMS/WhatsApp workflow setup where provider/channel configuration allows
- Stripe connection
- basic invoice/payment flow
- contract/e-signature workflow
- client onboarding trigger
- testing

Kydos does not add a separate programme CRM licence fee. Third-party/provider and messaging/usage charges may apply.

### Sales infrastructure

Kydos helps implement:

- sales pipeline
- follow-up sequence
- lead notifications
- booking calendar
- payment flow
- agreement flow
- sales scripts

### Recruitment support

Includes support with:

- Account Manager recruitment
- Creative recruitment
- Sales Closer setup

Exact recruitment service scope and any external recruitment cost must be confirmed before work begins.

### Client acquisition launch

Includes implementation support for the agency's initial Meta lead-generation campaign.

Participant provides ad spend.

Recommended initial ad budget:
£300.

Ad results are not guaranteed.

## Support

Priority implementation WhatsApp support for 12 weeks from programme start.

## Completion

Build With Us is complete when the agreed infrastructure has been built, tested and handed to the participant.

The participant remains responsible for running the agency and managing the team.
