# Hook Library

Use these as structures, not copy-and-paste lines.

## Problem hooks

- If you're doing [activity] but still not getting [outcome], check this.
- The problem may not be [obvious issue].
- You're not short of [thing]. You're short of [real issue].
- This is why [common effort] is not working.

## Contrarian hooks

- More content is not always better.
- You probably do not need another platform.
- Stop measuring [vanity metric] before checking [business metric].
- The cheapest option can become the most expensive.

## Identity hooks

- If you run a [business type], this is for you.
- For founders who are tired of [problem].
- If you're the person still doing all of this yourself...

## Curiosity hooks

- The part nobody tells you about [topic].
- What happens after [event]?
- There is one thing we check before [action].
- Most people notice [surface issue]. We look at [deeper issue].

## Mistake hooks

- 3 mistakes we see businesses make with [topic].
- Before you spend another £1 on [thing], check this.
- The mistake is not [thing]. It is [thing].
- If we could fix one thing first, it would be this.

## Process hooks

- Here is exactly what happens after you enquire.
- This is how we take a client from [start] to [finish].
- Our monthly process in 30 seconds.
- What your Account Manager is actually doing behind the scenes.

## Proof hooks

- This is what changed when [anonymised condition].
- What we learnt from managing [type of account].
- One small change made the biggest difference.

## FAQ hooks

- "How long does this take?"
- "Do I need to provide the content?"
- "What if I don't have photos?"
- "Do I need to be on every platform?"

## Story hooks

- When we first started, we thought...
- A client once asked us...
- We nearly made this mistake ourselves...
- This is one thing we changed as the agency grew.

## Rule

Do not repeat the same hook structure every week.

A content calendar should feel intentional, not templated.
