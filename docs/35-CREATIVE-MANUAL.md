# Creative Manual

The Creative is responsible for visual execution.

The Creative turns approved strategy and copy into professional visual content.

## Core responsibilities

- static social graphics
- carousels
- story designs
- reel/video editing
- subtitles
- visual consistency
- correct exports
- source/editable files
- asset organisation

## Capacity

Normal:
4 clients.

Upper working capacity:
5 clients.

## Weekly deadline

Weekly client batches are due by:

Monday, 1:00 PM UK time.

If the brief arrives late or key assets are missing, flag the issue immediately rather than silently missing the deadline.

## Inputs required

Before starting a post, confirm:

- approved concept
- format
- on-design text
- visual direction
- brand assets
- references
- video instructions
- CTA if visible
- due date

If the brief is unclear, ask the Account Manager.

## Design standard

Every design should be:

- readable on mobile
- consistent with the brand
- visually balanced
- free from spelling errors
- free from stretched or low-resolution assets
- appropriate to the platform
- professional enough to represent a paying client

## Static posts

Check:
- hierarchy
- headline clarity
- spacing
- contrast
- logo placement
- text density
- image quality

## Carousels

Each slide should have a job.

Typical flow:
1. strong cover
2. context/problem
3. insight
4. supporting point
5. supporting point
6. conclusion
7. CTA

Not every carousel needs seven slides.

Do not create unnecessary slides just to make it longer.

## Reels/videos

Check:
- strong opening frame
- clean cuts
- subtitles
- spelling
- audio level
- music appropriateness
- brand treatment
- mobile-safe text placement
- pacing
- CTA/end frame where required

## AI-generated visual rule

The normal Kydos-standard service uses human-created visual design and editing.

AI-generated visuals can be used when:
- the client requests them
- they suit the brief
- usage does not create misleading or inappropriate representation

Do not quietly replace real client imagery with AI people or scenes when authenticity matters.

## Stock assets

Use licensed/approved sources.

Current Kydos creative stack may include:
- Freepik
- Envato
- Adobe assets
- Canva assets

Check usage rights.

## File naming

Use:

YYYY-MM-DD - Client - Post/Week - Draft/Approved

Keep source files organised.

## Submission checklist

Before sending to Account Manager:

- [ ] brief followed
- [ ] copy exactly checked
- [ ] logo correct
- [ ] colours correct
- [ ] fonts correct
- [ ] images licensed/approved
- [ ] no competitor branding
- [ ] no placeholder content
- [ ] dimensions correct
- [ ] subtitles correct
- [ ] export quality checked
- [ ] editable/source file saved

## Corrections

Do not take corrections personally.

Apply them carefully and check whether the correction should become a permanent visual rule for the client.
