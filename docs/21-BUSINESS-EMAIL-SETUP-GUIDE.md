# Business Email Setup Guide

A professional agency should launch with email on its own domain.

Good:

hello@youragency.co.uk

sales@youragency.co.uk

accounts@youragency.co.uk

support@youragency.co.uk

Avoid using a personal Gmail, Yahoo or Outlook address as the main public business email after launch.

## Kydos model

Kydos currently uses GoDaddy email.

Kydos plans to move towards Microsoft 365.

The programme can therefore support either route, while GoDaddy remains the simpler default walkthrough.

## Recommended mailboxes

At launch:

### Owner

firstname@agency.co.uk

### General

hello@agency.co.uk

### Sales

sales@agency.co.uk

### Accounts

accounts@agency.co.uk

### Support

support@agency.co.uk

Not every address needs a separate paid mailbox.

Where supported, aliases can route to an existing mailbox.

## Account Manager addresses

As the team grows:

firstname@agency.co.uk

or

accountsmanager@agency.co.uk

Avoid creating client-facing addresses from personal email accounts.

## Setup checklist

- [ ] domain active
- [ ] email plan selected
- [ ] owner mailbox created
- [ ] hello address created
- [ ] sales address created
- [ ] accounts address created
- [ ] email signatures created
- [ ] MFA enabled
- [ ] recovery information stored
- [ ] SPF configured
- [ ] DKIM configured
- [ ] DMARC planned/configured
- [ ] test email sent to Gmail
- [ ] test email sent to Outlook
- [ ] reply tested
- [ ] mobile app configured

## Staff access

Each staff member should have their own login where practical.

Do not share one password across the team.

When a person leaves:
- suspend/remove access
- change shared credentials if any
- forward required mail
- preserve client records

## Sales emails

Sales automation should come from an authenticated business domain.

Monitor:
- bounce rate
- spam complaints
- reply rate
- domain reputation

Do not immediately send high-volume cold email from a brand-new domain without proper setup and warm-up considerations.

## Migration to Microsoft 365

If moving later:

1. inventory mailboxes
2. back up critical messages
3. create Microsoft 365 users
4. verify domain
5. migrate mail
6. switch DNS
7. configure authentication
8. test inbound/outbound
9. remove old service only when confirmed stable
