# Landing Page SOP

Kydos standard landing page price:
£250.

A landing page should have one primary conversion goal.

## Use cases

- Meta Ads
- Google Ads
- lead magnet
- event registration
- service campaign
- consultation booking
- recruitment/application

## Brief

Define:
- traffic source
- audience
- offer
- problem
- primary CTA
- form fields
- proof
- objections
- compliance
- tracking

## Structure

A useful structure may include:

1. headline
2. supporting value proposition
3. CTA
4. problem/context
5. benefits
6. how it works
7. proof/testimonials
8. FAQs/objections
9. final CTA
10. privacy/legal

Do not force this exact order if the offer needs something else.

## Headline

It should make the visitor understand:
- what this is
- who it is for
- why it matters

## Form

Collect only the information needed.

Too many fields can reduce conversions.

Too few fields may reduce lead quality.

Balance based on the sales process.

## Mobile

Most paid-social traffic may arrive on mobile.

Check:
- headline
- form
- buttons
- image cropping
- page speed
- sticky CTA
- keyboard/form usability

## Tracking

Before ads:
- page view
- form submit
- booking
- call click where relevant
- Meta/Google tracking as required

## CRM

Test the full path:

Ad -> Landing Page -> Form -> CRM -> Automation -> Salesperson

## QA

Use Website QA Checklist plus:

- [ ] offer matches ad
- [ ] form tested
- [ ] thank-you state works
- [ ] CRM lead created
- [ ] UTM parameters preserved where relevant
- [ ] conversion event fires
