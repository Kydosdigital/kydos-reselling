# Staff Onboarding Plan

## Before day one

- [ ] signed agreement
- [ ] ID/verification completed where required
- [ ] payment details
- [ ] role manual shared
- [ ] confidentiality terms
- [ ] company email
- [ ] CRM user
- [ ] Drive access
- [ ] communication channel
- [ ] manager assigned
- [ ] first-week schedule

## Day 1

Cover:
- company overview
- services
- packages
- team structure
- role boundaries
- communication rules
- data protection
- security
- deadlines
- escalation

## Day 2

Role-specific training.

Account Manager:
- research
- content calendar
- copy
- Creative brief
- approvals
- client communication

Creative:
- brand interpretation
- file structure
- design standards
- video standards
- weekly deadline

Sales:
- CRM
- lead speed
- qualification
- script
- pipeline
- payment handoff

Operations:
- trackers
- QA
- staffing
- escalation
- owner reporting

## Day 3

Shadow/test workflow.

Do not give a new staff member a difficult client with no support on day one.

## First week

Manager checks:
- communication
- understanding
- task completion
- quality
- access
- questions
- reliability

## First month

Review:
- client feedback
- recurring errors
- deadline performance
- role fit
- training needs

## Probation

Formal review points can include:
- 30 days
- 60 days
- end of 3 months

Document outcomes.
