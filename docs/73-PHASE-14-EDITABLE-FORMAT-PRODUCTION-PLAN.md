# Phase 14 Editable Format Production Plan

Phase 14 converts the repository source material into polished student-facing downloads.

## A. Word documents

Create:

- Programme Master Handbook
- Programme Legal and Policy Pack, draft
- Client Contracts and Service Schedules Pack, draft
- Staff, Contractor and Recruitment Pack, draft
- participant onboarding forms
- client onboarding forms
- role-specific agreements
- standalone policies where customers need individual files

Formatting standard:

- Kydos Digital title/header
- British English
- clear document status
- page numbers
- professional headings
- editable fields/placeholders
- no confidential real-client data

## B. PDF documents

Create PDF versions of:

- Programme Master Handbook
- legal pack
- client-contract pack
- staff-contract pack
- key checklists for participants who prefer read-only reference

All PDFs must be rendered and visually QA checked.

## D. Worked examples

Every major operating template should have:

1. clean version
2. Kydos-style worked example

Priority examples:

- client onboarding
- Content Rules Sheet
- content calendar
- Creative brief
- monthly report
- Account Manager candidate score
- Creative candidate score
- client health score
- Meta Ads campaign build
- Google Ads campaign build
- SEO audit
- Operations weekly report
- Done For You handover

## E. Professional review

After solicitor/accountant/adviser review:

1. apply changes to Markdown source
2. increment version
3. regenerate DOCX
4. regenerate PDF
5. re-run visual QA
6. replace DRAFT label only when formally approved

## F. Repository and portal

Repository remains the source of truth.

Portal/download files should be generated from the approved source wherever possible.

This reduces the risk of a Word/PDF version drifting away from the actual Kydos operating rules.
