# Website QA Checklist

Run this before every website launch.

## Content

- [ ] business name correct
- [ ] phone number correct
- [ ] email correct
- [ ] address correct
- [ ] spelling checked
- [ ] British English used where appropriate
- [ ] service claims reviewed
- [ ] prices correct
- [ ] CTA wording consistent
- [ ] no placeholder text
- [ ] no dummy contact information

## Navigation

- [ ] logo links home
- [ ] menu links work
- [ ] mobile menu works
- [ ] footer links work
- [ ] CTA buttons work
- [ ] no orphan key pages

## Forms

- [ ] contact form submits
- [ ] correct recipient receives notification
- [ ] CRM receives lead
- [ ] confirmation message works
- [ ] required fields work
- [ ] spam protection enabled where appropriate
- [ ] privacy notice linked

## Mobile

Check at minimum:

- [ ] iPhone-sized viewport
- [ ] Android-sized viewport
- [ ] tablet
- [ ] desktop

Check:
- [ ] no horizontal scrolling
- [ ] readable font size
- [ ] buttons easy to tap
- [ ] images fit correctly
- [ ] hero section works
- [ ] forms are usable
- [ ] sticky elements do not block content

## Performance

- [ ] images compressed
- [ ] no unnecessarily huge video files
- [ ] lazy loading where appropriate
- [ ] no obvious layout shift
- [ ] no broken assets

## SEO

- [ ] unique page title
- [ ] meta description
- [ ] one clear H1
- [ ] logical H2/H3 structure
- [ ] descriptive URLs
- [ ] image alt text
- [ ] internal links
- [ ] canonical tags
- [ ] robots configuration checked
- [ ] sitemap available
- [ ] Google Search Console ready

## Analytics

- [ ] GA4 installed
- [ ] Google Tag Manager checked where used
- [ ] Meta Pixel checked where used
- [ ] conversion events tested
- [ ] form conversion tested

## Social

- [ ] Open Graph title
- [ ] Open Graph description
- [ ] social preview image
- [ ] favicon

## Legal

- [ ] privacy policy
- [ ] cookie information
- [ ] consent mechanism where required
- [ ] company legal details where required
- [ ] registered office/company number where appropriate
- [ ] terms where relevant

## Technical

- [ ] SSL active
- [ ] www/non-www behaviour correct
- [ ] HTTP redirects to HTTPS
- [ ] primary domain correct
- [ ] 404 page works
- [ ] no broken links
- [ ] no staging URLs indexed
- [ ] backups/configuration recorded
