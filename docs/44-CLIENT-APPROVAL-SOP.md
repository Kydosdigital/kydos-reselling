# Client Approval SOP

Kydos does not publish unapproved standard content.

## Calendar approval

1. Internal review complete.
2. Calendar sent to client.
3. Target review window: 3 days.
4. Follow up if no response.
5. Apply revisions.
6. Record final approval.

Included:
2 revision rounds.

## Creative approval

After Creative production and Account Manager review:

1. send graphics/videos
2. clearly label the week/date
3. ask for approval or consolidated changes
4. record response
5. make corrections where required
6. save proof of approval

## Silence

Silence is not automatic approval.

If approval is delayed:
- chase
- document follow-up
- explain that posting dates may move
- wait for approval

## Approval evidence

Save:
- approval email
- WhatsApp screenshot
- CRM approval record
- signed-off document

Store in:
06 Approvals

## Consolidated feedback

Ask the client to provide consolidated feedback where possible.

Multiple conflicting messages from different people should be clarified before revisions begin.

## Approval authority

The onboarding form should name:
- primary approver
- secondary approver if any

Do not take instructions from an unauthorised person without checking.
