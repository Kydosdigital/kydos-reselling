# Website Development SOP

## Kydos standard price

Standard business website:
£500 for any 5 pages selected by the client.

Landing page:
£250.

E-commerce:
custom quotation.

Website rebuild:
custom quotation based on page count, complexity and existing condition.

## Stage 1, Scope

Before quoting, confirm:
- number of pages
- functionality
- copywriting
- brand assets
- integrations
- forms
- booking
- CRM
- analytics
- ecommerce
- membership
- migration
- hosting/domain
- deadline

## Stage 2, Brief

Use the Website Discovery Form and 5-Page Website Brief.

## Stage 3, Content

Collect:
- business information
- services
- audience
- proof
- photos
- team
- FAQs
- CTA
- legal/compliance wording

## Stage 4, Structure

Define:
- sitemap
- navigation
- page goal
- CTA
- content hierarchy

## Stage 5, Build

Build mobile-first.

Include:
- responsive layout
- forms
- basic on-page SEO
- image optimisation
- analytics readiness
- privacy/cookie implementation support
- CRM integration where included

## Stage 6, Internal QA

Use Website QA Checklist.

## Stage 7, Client review

Send staging/review link.

Collect consolidated changes.

Apply the project's agreed revision allowance.

## Stage 8, Launch

Confirm:
- domain
- SSL
- forms
- mobile
- analytics
- tracking
- redirects
- sitemap
- robots
- legal links

## Stage 9, Post-launch

Test:
- homepage
- navigation
- forms
- booking
- payment if relevant
- analytics
- mobile
- key conversions

## Scope change

Quote separately for:
- new pages beyond agreed scope
- ecommerce
- advanced portals
- custom software
- new integrations
- major copy expansion
- large migration
