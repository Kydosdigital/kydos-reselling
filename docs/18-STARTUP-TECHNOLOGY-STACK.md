# Startup Technology Stack

Last reviewed: 31 August 2026

This is the minimum Kydos-style technology stack for launching the agency.

The principle is simple: buy the tools needed to sell, deliver, communicate, get paid and stay organised. Do not collect software subscriptions that have no immediate job.

## 1. Company formation

Recommended beginner route:
- ANNA Money using the current Kydos referral link or code

Purpose:
- company formation
- initial business-account route
- optional admin tools

Longer-term main banking in the Kydos model:
- NatWest

## 2. Accounting

- FreeAgent
- external accountant

Purpose:
- bookkeeping
- transaction reconciliation
- invoices/accounting records
- tax visibility
- accountant collaboration

## 3. Domain

- GoDaddy

Every agency should own its own domain.

Examples:
- youragency.co.uk
- youragency.com

The domain should be registered in the agency owner's/company's account, not in a freelancer's personal account.

## 4. Business email

Kydos currently uses GoDaddy email and plans to move to Microsoft 365.

Programme rule:
Use a proper domain-based business email.

Good:
hello@youragency.co.uk

Avoid using a personal Gmail address as the main public agency email after launch.

## 5. CRM

The programme customer sets up their own branded CRM through the Kydos referral route.

Kydos does not charge an additional programme licence fee for the customer's own CRM setup.

The CRM should handle:
- lead capture
- pipeline stages
- contact records
- email
- SMS
- WhatsApp workflows
- booking calendar
- invoices/payment links where configured
- contracts/e-signature
- social scheduling
- follow-up automation
- reporting

The customer's agency branding should replace provider-facing branding wherever the chosen plan supports it.

## 6. Payments

- Stripe

Use for:
- card payments
- payment links
- recurring payments
- CRM-connected billing

The business bank receives settlements.

## 7. File storage

- Google Drive
- Google Forms

Internal company Drive:
- Company Admin
- Finance
- Staff
- Sales
- Marketing
- Templates
- Clients

Each client gets a dedicated client folder.

## 8. Password and access security

Do not teach plain-text password storage as the preferred future standard.

Use:
- delegated Meta/Google/platform access where available
- a reputable password manager where actual credentials must be shared
- least-privilege access
- immediate access removal during offboarding

Candidate password managers can include established business products such as 1Password or Bitwarden. The final programme should choose one recommended default after a dedicated security review.

Never put:
- online banking password
- Stripe owner password
- Companies House personal code
- primary email password

inside a general client/staff Google document.

## 9. Creative stack

Core:
- CapCut
- Adobe Photoshop / Adobe Creative Cloud where required
- Canva where the Creative can maintain professional standards
- Freepik
- Envato

The agency does not need every tool on day one.

The Creative's workflow should determine the final combination.

## 10. Social scheduling

Use the CRM's social scheduling system where it supports the required platforms and workflow.

Where a platform requires native posting or functionality not supported by the CRM, use the platform's native tool.

## 11. Communication

Internal/client:
- business email
- WhatsApp

Programme support:
- WhatsApp according to programme tier

Important:
WhatsApp is a communication tool, not the master record for contracts, passwords, invoices or client assets.

## 12. Website

Blueprint:
- website build is not included
- Kydos can provide the starter website separately

Build With Us:
- 5-page website included

Done For You:
- 5-page website included

Website stack can vary according to the build method. The participant should not need to learn development to run the agency.

## 13. Analytics and advertising

Required when launching:
- Meta Business tools
- Meta Ads Manager
- Meta Pixel/Conversions setup where relevant
- Google Analytics 4
- Google Tag Manager where appropriate
- Google Search Console
- Google Ads where sold or used

## 14. Recruitment

- LinkedIn for Account Manager recruitment
- Kydos recruitment network/contact for Creatives
- Google Drive/Forms or CRM for candidate records
- standard scorecards and test tasks

## 15. Minimum stack before advertising

Before the agency spends money acquiring clients, confirm:

- [ ] company established
- [ ] business bank
- [ ] accounting system
- [ ] accountant
- [ ] domain
- [ ] business email
- [ ] website or launch landing presence
- [ ] CRM
- [ ] Stripe
- [ ] booking calendar
- [ ] contracts/e-signature
- [ ] client onboarding form
- [ ] client Drive template
- [ ] Account Manager
- [ ] Creative
- [ ] Sales Closer
- [ ] privacy/data protection basics
- [ ] Meta Ads account

## Buying rule

If a subscription does not help the business:
- acquire a client
- serve a client
- get paid
- manage the team
- protect the business
- measure performance

then question whether it is needed at launch.
