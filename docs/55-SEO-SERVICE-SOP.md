# SEO Service SOP

SEO is sold as an ongoing visibility and search-performance service.

Do not guarantee page-one rankings.

## Kydos packages

### SEO Essentials, £150/month

Best for:
small/local businesses that need core fundamentals.

### SEO Growth, £299/month

Best for:
businesses actively trying to grow organic traffic.

### SEO Authority, £500/month

Best for:
more competitive businesses where SEO is a serious acquisition channel.

Use the Package Breakdown document for detailed inclusions.

## Onboarding

Collect:
- website
- services
- target locations
- priority services
- customer types
- competitors
- GA4 access
- Search Console access
- CMS access
- Google Business Profile where relevant
- past SEO work
- migration/history
- compliance restrictions

## Initial audit

Review:
- crawlability
- indexation
- titles
- descriptions
- headings
- content quality
- keyword targeting
- internal links
- canonicals
- redirects
- sitemap
- robots
- mobile
- speed
- structured data
- local SEO
- backlink profile
- analytics/tracking
- conversion paths

## Keyword map

Assign:
- primary intent
- primary keyword/theme
- secondary terms
- target URL

Avoid multiple pages competing for the same intent without reason.

## On-page optimisation

May include:
- title
- meta description
- H1
- H2/H3
- opening copy
- body copy
- internal links
- image alt text
- CTA
- schema where relevant

## Content

Content should answer actual search intent.

Avoid:
- generic filler
- keyword stuffing
- publishing articles with no internal links
- creating dozens of thin pages
- unsupported claims

## Technical work

Separate:
- recommendations
- minor fixes included in package
- major development work requiring separate quotation

## Local SEO

Where relevant:
- Google Business Profile
- consistent business details
- service/location relevance
- reviews strategy
- local landing pages where justified

## Reporting

Monthly:
- organic clicks
- impressions
- rankings/themes
- leads/conversions where trackable
- pages improved
- technical issues
- content delivered
- next actions

## Quality rule

SEO work should improve:
- search understanding
- user usefulness
- conversion path

It should not exist only to "put keywords somewhere."
