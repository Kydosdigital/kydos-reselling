# Task Management SOP

The agency should not be run from memory or scattered WhatsApp messages.

Every operational task must have:

- owner
- client/project
- clear action
- due date
- status
- priority where useful

## Task statuses

Recommended:

- Not Started
- In Progress
- Waiting on Client
- Waiting Internally
- Review
- Approved/Ready
- Completed
- Blocked

## Task types

Examples:

- onboarding
- research
- calendar
- internal review
- client approval
- Creative brief
- design
- video
- scheduling
- report
- ad campaign
- SEO work
- website task
- payment follow-up
- renewal

## Naming

Use action language.

Weak:
"September"

Better:
"Prepare September content calendar for Client X"

## Due dates

The due date should reflect the internal deadline, not only the final client deadline.

Example:

Client post due Friday.

Creative internal due:
Monday 1:00 PM.

Account Manager review:
Tuesday.

Client approval:
Wednesday/Thursday.

Scheduling:
before Friday.

## Waiting on client

Do not leave task overdue with no context.

Move to:
Waiting on Client

Record:
- what is needed
- date requested
- follow-up date

## Recurring tasks

Automate where possible:

- monthly calendar
- weekly Creative brief
- monthly report
- invoice check
- renewal check
- compliance review

## Daily use

Each team member should begin the day by checking:

1. overdue
2. due today
3. blocked
4. waiting for their response
5. upcoming

## Operations Manager

Reviews:
- overdue tasks
- blocked tasks
- unassigned tasks
- high-risk client tasks
- team workload

## WhatsApp rule

WhatsApp can create a task.

WhatsApp is not the task-management system.

If a client asks:
"Please change Post 4"

the Account Manager should:
- acknowledge
- create/update the task
- record the change
- update permanent client rules if needed
