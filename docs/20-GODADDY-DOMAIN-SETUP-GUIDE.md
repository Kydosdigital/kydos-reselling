# GoDaddy Domain Setup Guide

The Kydos programme recommends GoDaddy as the default domain provider because it is familiar, widely used and can also support email and DNS management.

The agency owner should control the domain account.

## 1. Choose the domain

Preferred order:

1. exact .co.uk
2. exact .com
3. a clean alternative that still matches the agency name

Avoid:
- long names
- difficult spellings
- multiple hyphens
- numbers unless meaningful
- names that may infringe another brand

## 2. Create the account correctly

Use:
- the owner's or company-controlled email
- strong unique password
- multi-factor authentication

Do not let:
- a freelancer
- website developer
- designer

own the domain in their personal account.

They can be given delegated access where needed.

## 3. Buy the domain

Before checkout:

- check the renewal price
- check whether any bundled products are actually needed
- avoid buying unnecessary extras
- confirm registration term
- enable automatic renewal if appropriate
- ensure payment card belongs to the business where possible

## 5. DNS

Common records may include:

- A record
- CNAME
- MX
- TXT
- SPF
- DKIM
- DMARC
- verification records for Meta, Google or email providers

Do not delete existing DNS records without understanding what they do.

A single wrong DNS change can break:
- website
- email
- verification
- tracking

## 6. Website connection

The website developer may request DNS changes.

Before changing anything:
- screenshot current DNS
- record the requested change
- confirm destination
- apply one controlled change at a time
- test website and email afterwards

## 7. Email connection

If using GoDaddy email, follow the supplied DNS setup.

If moving to Microsoft 365 later:
- plan migration
- preserve mailboxes
- update MX records
- configure SPF/DKIM/DMARC
- test delivery before considering the migration complete

## 8. Security

- enable MFA
- use unique password
- limit admin access
- remove former staff
- review delegated users
- keep domain locked where appropriate
- keep contact details current

## 9. Renewal

The domain is a critical business asset.

Create calendar reminders:
- 60 days before renewal
- 30 days before renewal
- 7 days before renewal

## 10. Programme rule

The domain must be registered to the participant's own agency account.

Kydos can configure the domain for Build With Us and Done For You customers, but ownership remains with the customer.
