# Participant Lifecycle

## 1. Lead

Source:

- Meta
- website
- referral
- organic
- other

CRM stage:
New Programme Lead

## 2. Qualified prospect

Salesperson confirms:

- business intent
- tier fit
- start timing
- budget readiness
- expectations

## 3. Consultation

Outcome:

- Blueprint
- Build With Us
- Done For You
- nurture
- lost

## 4. Payment

Requirements:

- full payment
- agreement
- checkout consent where applicable

## 5. Participant onboarding

- payment confirmation
- portal
- intake
- support dates
- implementation owner

Status:
Onboarding

## 6. Build

Status:
Build Active

Blueprint:
participant-driven.

Build With Us:
shared actions.

Done For You:
Kydos-led implementation with participant approvals/dependencies.

## 7. Launch ready

Requirements:

- sales system tested
- fulfilment ready
- team ready
- client onboarding ready
- ad/lead route ready

Status:
Launch Ready

## 8. Live

Client acquisition starts.

Status:
Live

## 9. Handover support

Done For You only.

Formal handover date starts the 90-day post-handover support window.

## 10. Alumni / materials access

Active personal support has ended.

Participant retains material access according to agreement.

Potential future services:

- extended consulting
- recruitment
- specialist training
- website changes
- CRM support
- advanced ads training
