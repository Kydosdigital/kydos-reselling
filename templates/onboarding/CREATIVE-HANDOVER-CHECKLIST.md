# Creative Handover Checklist

Client:

Creative:

Account Manager:

## Before first design

- [ ] approved brand assets received
- [ ] logo received
- [ ] fonts confirmed
- [ ] colours confirmed
- [ ] brand guidelines reviewed
- [ ] approved image/video library available
- [ ] examples client likes reviewed
- [ ] examples client dislikes reviewed

## Client-specific rules

- [ ] visual restrictions reviewed
- [ ] prohibited imagery reviewed
- [ ] logo placement rules reviewed
- [ ] photography style reviewed
- [ ] reel/video style reviewed
- [ ] text density expectations reviewed
- [ ] previous corrections reviewed

## Weekly workflow

The Creative receives:
- approved concept
- format
- on-design text
- visual direction
- reference
- CTA where visual
- video instruction
- due date

Weekly deadline:
Monday, 1:00 PM UK time.

## Before submission to Account Manager

- [ ] correct dimensions
- [ ] correct spelling
- [ ] correct client logo
- [ ] correct brand colours
- [ ] no unapproved stock imagery
- [ ] no accidental competitor branding
- [ ] text readable on mobile
- [ ] video subtitles checked
- [ ] audio rights/usage considered
- [ ] exports named correctly
- [ ] editable/source file retained

## Rule

The Creative does not rewrite strategy independently.

If the brief is unclear or unsuitable, ask the Account Manager before changing the concept.
