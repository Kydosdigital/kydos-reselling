## Security rules

Prefer:
- delegated user access
- business-manager access
- role-based permissions

Avoid:
- sharing owner's main password
- sending credentials in ordinary WhatsApp messages
- storing passwords in unrestricted Google Docs

Where credentials are unavoidable, use the approved password manager.

## Offboarding

- [ ] remove agency access
- [ ] transfer assets
- [ ] confirm ownership
- [ ] export required records
