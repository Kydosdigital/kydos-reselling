# Creative Test Task

This is an unpaid recruitment assessment.

It must not be used as live client work.

## Fictional client

Northline Physio

Brand direction:
- modern
- trustworthy
- clean
- professional
- not overly clinical

Colours:
Navy, white, warm neutral accent

## Task 1, Static graphic

Create a 1080 x 1350 Instagram graphic.

Headline:

"Back pain advice should not start with panic."

Supporting line:

"Start with assessment, context and the right plan."

## Task 2, Carousel cover

Create a cover for:

"3 mistakes people make when returning to exercise after injury"

## Task 3, Short video

Create a 15 to 20 second reel from supplied dummy B-roll.

Requirements:
- subtitles
- clean pacing
- simple branded ending
- mobile-safe text

## Submit

- final exports
- source/editable file or accessible project link
- short note explaining design choices

## We assess

- typography
- hierarchy
- spacing
- brand consistency
- mobile readability
- video pacing
- attention to detail
- originality
- file organisation
