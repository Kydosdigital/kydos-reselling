## Correct account

- [ ] correct client
- [ ] correct month/week
- [ ] correct package
- [ ] correct platform
- [ ] correct service

## Strategy

- [ ] aligns with client goal
- [ ] useful to target audience
- [ ] not generic
- [ ] not repetitive
- [ ] CTA fits objective
- [ ] appropriate content mix

## Copy

- [ ] spelling
- [ ] grammar
- [ ] British English where required
- [ ] facts checked
- [ ] names correct
- [ ] dates correct
- [ ] prices correct
- [ ] links correct
- [ ] no unsupported claims
- [ ] no prohibited wording
- [ ] client tone followed

## Creative

- [ ] correct logo
- [ ] correct colours
- [ ] correct fonts
- [ ] readable on mobile
- [ ] images high quality
- [ ] no stretched assets
- [ ] no competitor branding
- [ ] dimensions correct
- [ ] subtitles correct
- [ ] safe areas respected
- [ ] source file saved

## Client rules

- [ ] Content Rules Sheet checked
- [ ] previous corrections respected
- [ ] compliance notes checked
- [ ] required disclaimer included

## Scope

- [ ] within package
- [ ] revisions tracked
- [ ] no unapproved extra work promised

## Approval

- [ ] internal approval complete
- [ ] client approval required?
- [ ] approval evidence stored

## Outcome

- [ ] approved internally
- [ ] corrections required
- [ ] escalate
