# Payroll and PAYE Readiness Checklist

This checklist is for a business that is becoming a UK employer.

Use the accountant/payroll professional to confirm the exact setup.

## Employer setup

- [ ] confirm whether PAYE registration is required
- [ ] register as an employer where required
- [ ] obtain PAYE reference
- [ ] obtain Accounts Office reference
- [ ] choose payroll software/provider
- [ ] set payroll frequency
- [ ] define payday
- [ ] define approval process

## Employee

For each UK employee:

- [ ] signed employment agreement
- [ ] personal details
- [ ] address
- [ ] National Insurance number where available/required
- [ ] starter information
- [ ] tax code process
- [ ] right-to-work check
- [ ] salary
- [ ] hours
- [ ] pension assessment
- [ ] bank details securely held

## Payroll run

- [ ] gross pay checked
- [ ] tax checked
- [ ] employee NIC checked
- [ ] employer NIC checked
- [ ] pension checked
- [ ] deductions checked
- [ ] payslip generated
- [ ] FPS submitted on time where required
- [ ] employee paid
- [ ] HMRC liability recorded

## Record keeping

Store:
- payroll reports
- payslips
- submissions
- HMRC notices
- pension records
- salary changes
- leave/sickness records where relevant

## Sponsor-readiness note

For sponsored staff, payroll must reflect the genuine role and actual salary.

Do not create a paper salary that is not genuinely paid.

Any proposed sponsored role and salary must be checked against current immigration rules by the regulated adviser.
